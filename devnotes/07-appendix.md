# 7. Appendix & Quick Reference

---

## Terminal Commands (Linux)

| Command | Purpose |
|---------|---------|
| `npm run dev` | Start frontend |
| `npm run start:dev` | Start backend |
| `npx prisma migrate dev` | Apply migrations |
| `npx prisma studio` | Open DB viewer |
| `docker-compose up --build` | Build & start containers |

---

## VS Code Tips

- Install extensions: ESLint, Tailwind CSS IntelliSense, Prisma  
- Use integrated terminal: Ctrl+`  
- Split editor: Ctrl+\  

---

## Best Practices

- Keep `/apps/web/components` organized  
- Reuse Tailwind classes via custom design system  
- Commit early, push often  
- Modularize backend controllers/services by domain
